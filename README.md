# Cueline

A knob-driven teleprompter for iPad and laptop: scroll mode, take mode with a timestamped take log, and DaVinci Resolve marker export.

**Use it:** open the site in Safari on the iPad, tap Share › Add to Home Screen, and launch Cueline from its icon for full screen.

Scripts and take logs are stored only in the browser on each device. Nothing is uploaded.

Works with any Bluetooth keyboard, clicker or the Cueline Knob (arrow keys, Space, G, X, Page Up/Down).
